01. Player Fantasy & Audience

Subatomic Containment Specialist

Player Fantasy: You control a high-voltage magnetic containment core inside an unstable reactor. Mastering the rhythm of incoming charges makes you feel like a razor-sharp reflex operator channeling chaotic plasma into pure energy.

Target Audience: Casual arcade and rhythm-reflex players (ages 10+) looking for an immediately readable, high-contrast 3–5 minute browser or mobile session with zero tutorial bloat.

02. Core Loop (Action → Feedback → Consequence → Next Decision)
1. ACTION

Flip magnetic polarity between Blue (+) and Orange (−) using a single button.

2. FEEDBACK

Core morphs shape (Circle/Hexagon), emits harmonic synth chime + radial shockwave or warning buzz.

3. CONSEQUENCE

Matches add +10×Multiplier PTS & restore shield at 8x streak; mismatches shatter 1 shield ring.

4. NEXT DECISION

Read the next descending wave's shape/color and time the next polarity flip before impact.

03. Win, Loss, Restart, Pause & Onboarding States
ONBOARDING STATE

First 2 waves are slow, deterministic single orbs (1 matching, 1 opposite with a pulsing visual ghost ring) so players learn without text.

WIN STATE (1,500 PTS)

Reached after ~3.5 minutes of sustained play. Triggers Overdrive Stabilization victory screen, accuracy report, and Freeplay option.

LOSS STATE (0 SHIELDS)

Losing all 3 shield segments triggers Core Containment Breach, logging survival duration, peak streak, and failure point.

PAUSE STATE (P / ESC)

Freezes delta-time physics and audio oscillators immediately with an overlay showing current telemetry and resume/restart actions.

RESTART STATE (R)

Instant zero-load state reset at any moment (or after Win/Loss) that archives the run directly into the Playtest Sheet below.

05. Deliberate Scope Cuts
  • ✕ No 2D Spatial Movement: Cut X/Y joystick movement so 100% of cognitive load stays on single-button timing and polarity reading.
  • ✕ No Multi-Currency Upgrades or Shops: Cut meta-progression menus to keep the 3–5 minute arcade session self-contained.
  • ✕ No External Image/Audio Dependencies: Cut external sprite sheets and MP3s in favor of deterministic Canvas geometry and WebAudio synthesis.
